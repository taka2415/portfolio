Overview

The EMIT (Emerging Mixed-signal Integrated circuit Technology) Lab develops mixed-signal accelerators for combinatorial optimization, including a silicon-proven simulated bifurcation machine in 180 nm CMOS. Simulated bifurcation solves Ising-model problems by integrating the classical dynamics of a network of Kerr-nonlinear parametric oscillators, whose bifurcation drives spins toward a low-energy configuration.

My work characterizes the algorithm on an edge GPU, as a software baseline and a design reference for the hardware effort.

First-author manuscript on GPU benchmarking of simulated bifurcation, with two co-authors, submitted to IEEE Transactions on Emerging Topics in Computing (Aug 2026). Under review; title withheld until a decision.

Benchmarking Framework

  • Built a PyTorch benchmarking framework for the ballistic simulated bifurcation solver on an NVIDIA Jetson Orin Nano, targeting MAXCUT and QUBO instances from 100 to 4500 nodes
  • Swept numeric precision (INT8, FP16, FP32, FP64) across problem sizes, measuring per-iteration latency, time-to-solution, and solution quality against a shared reference set over multiple seeds per configuration
  • Compared edge-GPU execution against CPU execution of the same solver to characterize where GPU offload pays off
  • Profiled kernel-level metrics, including memory bandwidth utilization and launch overhead, to explain where each precision saturates

Measurement Methodology

  • Designed the measurement procedure for reproducibility across JetPack power modes: locked GPU clocks, warm-up runs, thermal-throttle guarding, explicit TF32 control, and multi-seed statistics
  • Identified and fixed an integrator synchronization bug and a coupling-parameter error in the solver, then re-collected all timing data under the corrected implementation
  • Wrote the data-analysis and plotting pipeline, including best-fit model selection (linear, quadratic, saturating power law) for scaling curves
  • Released a public code and data artifact repository with documented provenance for every result series

Link to the Mixed-Signal Hardware

  • Analyzed the lab's 180 nm mixed-signal simulated bifurcation accelerator to align the GPU solver's formulation with the hardware implementation: discretized ballistic update, coupling normalization, and time-step selection
  • Mapped the numeric-precision results onto mixed-signal design constraints, using the INT8 through FP64 sweep as a proxy for the DAC/ADC resolution and analog noise budget a hardware implementation must tolerate

Writing

  • Drafted the full manuscript in IEEE format, managed the bibliography, and coordinated revisions with two co-authors

Focus Areas

Hardware/algorithm co-design for Ising-model solvers, low-precision numerics for optimization, and edge-GPU benchmarking methodology.
